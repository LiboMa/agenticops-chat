# Documentation map

> 文档地图：哪些文档是**持续维护**的，哪些是**带日期的历史快照**，以及双语 README 的维护规则。

AgenticOps documentation lives in three layers. Only the first layer is edited in place; the
other two are appended to, never rewritten.

## 1. Living documents — kept current with the code

| Document | What it is | Update when |
|---|---|---|
| [`../README.md`](../README.md) · [`../README_CN.md`](../README_CN.md) | Product overview, quick start, interfaces, deployment, release history — **one document in two languages** | Any user-visible feature, model default, endpoint group, page, or release |
| [`WORKFLOW.md`](WORKFLOW.md) | End-to-end workflow guide with Mermaid diagrams, tutorials, CLI/API quick references | Every feature that changes how an operator works with the system |
| [`DESIGN.md`](DESIGN.md) | System design (Chinese). Section 0 indexes every architectural increment since 2.0.1 and points at the authoritative release note | New subsystem, changed module boundary, changed data model |
| [`PROJECT-STATS.md`](PROJECT-STATS.md) | Code metrics and key counts — regenerated by the script embedded in the file | Each release (run the script; do not hand-edit numbers) |
| [`../skills/ADDING_SKILLS.md`](../skills/ADDING_SKILLS.md) | How to write, import (URL / git / zip), scan, promote and sandbox skills | Any change to the skills pipeline |
| [`../CLAUDE.md`](../CLAUDE.md) | Development guide for humans and agents working on the code: architecture, module map, config keys, rules | Any change to modules, config surface, or engineering rules |
| [`setup/`](setup/) | Integration setup guides (Slack bot manifests, dual-bot setup) | When an integration's setup steps change |

### Bilingual rule (README.md ↔ README_CN.md)

`README.md` and `README_CN.md` are the **same document in two languages**. Any change to one is
made to the other **in the same commit**: sections map one-to-one, table rows map one-to-one,
links are identical. A pull request that touches only one of them is incomplete. The Chinese file
keeps its existing name (`README_CN.md`) — external links depend on it.

## Conventions

- Language: `README.md`, `WORKFLOW.md` and the E2E reports are English; `README_CN.md`,
  `DESIGN.md` and the 2.5.0 release note are Chinese. New documents pick one and stay in it.
- Numbers (endpoint counts, test counts, skill counts, page counts) are measured, not estimated —
  the measuring commands live in `PROJECT-STATS.md`.
- Protected files (never delete, move or modify): `RAW-Idea-latest-v3.md`, `RAW-Creative-Idea.md`,
  `docs/use-cases/*`, `docs/MVP-1.0.0-RELEASE.md`.
