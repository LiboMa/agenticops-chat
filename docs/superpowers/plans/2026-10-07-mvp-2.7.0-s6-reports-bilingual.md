# MVP-2.7.0 S6 Reports & Bilingual Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reports get a version, a content hash, a source language and an owner. Each report gets a Chinese and an English rendering, produced by a guarded cheap-model translation that never alters a protected value (fails closed). Reports can be exported (HTML, plus PDF / DOCX when available) and printed, and publishing is pinned to a version and language, shows its destination, and is idempotent.

**Architecture:**
- **Data:** new `reports` columns plus a `content_renderings` table, via the 2.7.0 additive migration.
- **Services:**
  - `services/report_content.py` stamps the hash and language (SQLAlchemy `before_insert` / `before_update` on `Report`);
  - `services/report_access.py` gates visibility (the `chat_access` pattern);
  - `services/content_protect.py` (pure) swaps every protected value for a placeholder and checks they all come back;
  - `services/content_rendering.py` reads renderings (never a model) and runs translations in a background thread (one process, S1).
- **Routes:**
  - `GET /api/content/report/{id}/rendering`;
  - `POST /api/content/report/{id}/translations`;
  - `GET /api/reports/{id}/export`;
  - `POST /api/reports/{id}/publish`, extended.
- **Frontend:** behaviour sits in pure `lib/reportView.ts`, `lib/download.ts` and `lib/publish.ts`; the pages stay thin.

**Tech Stack:** FastAPI + SQLAlchemy, Bedrock converse (the cheap model, temperature 0), `notify/report_formatter`, React 18 + TanStack Query, pytest, vitest. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-07-mvp-2.7.0-s6-reports-bilingual-design.md`

## Global Constraints

- Backend tests run ONLY through `.superpowers/aiops-pytest.sh <log> <tests…>`, which uses a throwaway DB and runs `init_db` on every run. Never use plain pytest.
- Frontend: `npx tsc --noEmit` and `npx vitest run`.
- Build: back up and restore `dist/` and `tsconfig.tsbuildinfo` around it; never commit them.
- Commits:
  - explicit paths only;
  - end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - no push or tag without the owner's OK.
- Shared files (`web/app.py`, `web/schemas.py`, `models.py`, `config.py`, `config/settings.yaml`, `api/types.ts`, locales, CLAUDE.md, the README pair, WORKFLOW, RELEASE, roadmap): run `git status -- <file>` and message the peer `auto-execute-approved-changes` before editing; commit the same turn.
  - `config/settings.yaml` carries the owner's uncommitted edits. Add only the new key, and commit with `git commit -p`-equivalent care: stage only the new hunk via a patch file. Never commit the owner's lines.
- **Handlers:** new DB handlers are plain `def`; no blocking network call in an `async def`. Translation runs in a `threading.Thread` and never on the event loop.
- **Config:** no hard-coded configurable values. The new key is `report_translation_model_id` (`""` = `bedrock_model_id_cheap`): the schema goes in `config.py`, the value in `settings.yaml`.
- **Contract values:**
  - rendering status `ready|pending|missing|failed|stale`;
  - languages `zh|en`; export language `zh|en|zh-en`; export format `html|pdf|docx`;
  - `Idempotency-Key` 16–200 characters;
  - error codes `rendering_not_ready`, `format_unavailable`, `protected_values_changed`, `model_failed`, `interrupted`.
- **Frontend rules:**
  - Display code never calls `authz.check`.
  - Every new locale key goes in both `en.json` and `zh.json`.
  - Every overlay animates in with slideInRight and closes on ESC.
  - Report bodies render through the existing `renderMarkdown`, which escapes HTML; never through raw HTML.

## Review Focus

1. **A translated report keeps every command, `I#` ref, ARN and number exactly:** a model that drops, duplicates or invents a placeholder yields `failed`, never a partial text. Pinned in Task 3 (`content_protect`) and Task 4 (`test_tampered_translation_fails_closed`).
2. **A private report never reaches another user:** list, get, rendering, translations, export, publish and share. Pinned in Task 2 (`test_every_report_route_hides_a_private_report`).
3. **Switching language never calls a model,** and a GET never translates. Pinned in Task 4 (`test_get_rendering_never_calls_the_model`).
4. **Publishing twice with one key sends once,** and publish sends exactly the pinned version and language. Pinned in Task 6.
5. **Export of a language that is not ready is refused,** never a silent fallback to the other language. Pinned in Task 5 (`test_export_of_a_language_not_ready_is_409`).

### Task 3: Protected values (pure)

**Files:**
- Create: `src/agenticops/services/content_protect.py`; test `tests/test_content_protect.py`.

**Interfaces:**
- Produces:

```python
class ProtectedValuesChanged(ValueError): ...
def protect(text: str) -> tuple[str, list[str]]          # masked text with ⟦P0⟧…⟦Pn⟧, values in order
def restore(masked: str, values: list[str]) -> str       # raises ProtectedValuesChanged unless each ⟦Pi⟧ appears exactly once and no others
def protected_hash(text: str) -> str                     # sha256 of "\x1f".join(protect(text)[1])
```

  - What is protected, in this order (earlier patterns win; every match is replaced once):
    1. fenced code blocks;
    2. inline code;
    3. URLs;
    4. ARNs;
    5. object refs `[IRCP]#\d+`, evidence refs `\bE-?\d+\b` and check ids `\bpc-\d+\b`;
    6. AWS-style ids `\b(i|vol|sg|subnet|vpc|eni|ami|rtb|igw|nat|db|cluster|arn)-[0-9a-z-]+\b` and IPv4 addresses;
    7. every remaining number `\d+(?:[.,:]\d+)*%?`.
