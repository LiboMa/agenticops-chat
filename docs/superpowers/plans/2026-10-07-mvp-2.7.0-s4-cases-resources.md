# MVP-2.7.0 S4 Cases & Resources — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cases becomes a URL-driven queue plus reading pane on HealthIssue reads. Add one top-bar account scope, append-only issue notes, «Ask Agent», and an honest Resources table.

**Architecture:**
- Server-side filtering on `GET /api/health-issues`.
- Notes are `note_added` PipelineEvents inserted in the request's own transaction, gated by the new `issue.note` permission.
- Resource health reuses `graph/query_service.health_overlay`.
- Frontend behaviour lives in pure `lib/` helpers: `caseQueue`, `accountScope`, `resourceTable`, `contextRef`, `activity`. Pages and components stay thin.
- The `issues` route becomes a nested layout route, so the queue never remounts.

**Tech Stack:** FastAPI + SQLAlchemy, React 18 + react-router 6 + TanStack Query + Tailwind, pytest, vitest. No new dependencies.

**Spec:** [`docs/superpowers/specs/2026-10-07-mvp-2.7.0-s4-cases-resources-design.md`](../specs/2026-10-07-mvp-2.7.0-s4-cases-resources-design.md)

```python
"""Append-only notes on an issue (MVP-2.7.0 S4): one PipelineEvent per note, written in the caller's transaction —
never through pipeline_events.log_event, which swallows errors (a note must not be acknowledged unless stored)."""
import re
from datetime import datetime, timezone

from agenticops.models import PipelineEvent

_BAD = re.compile(r"[\x00-\x08\x0b\x0c\x0e-\x1f\x7f]")
MAX_NOTE_CHARS = 8000


class NoteRejected(ValueError):
    pass


def clean_note(content: str) -> str:
    text = (content or "").strip()
    if not text:
        raise NoteRejected("a note needs some text")
    if len(text) > MAX_NOTE_CHARS:
        raise NoteRejected(f"a note is at most {MAX_NOTE_CHARS} characters")
    if _BAD.search(text):
        raise NoteRejected("a note may not contain control characters")
    return text


def add_note(session, issue, content: str, actor) -> PipelineEvent:
    ev = PipelineEvent(health_issue_id=issue.id, event_type="note_added", stage="note", status="recorded",
                       detail={"content": clean_note(content)}, actor=actor.key[:100],
                       trace_id=issue.trace_id, created_at=datetime.now(timezone.utc))
    session.add(ev)
    session.flush()
    return ev
```

  Check `PipelineEvent.detail`'s column type. It is `Text` in `models.py` (~797), so store `json.dumps({"content": text})`. The response is built from the cleaned text, not by re-reading `detail`.
