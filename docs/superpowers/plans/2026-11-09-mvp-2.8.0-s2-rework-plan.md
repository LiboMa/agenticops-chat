**Interfaces（产出）**

  - `Role = Literal["admin", "writer", "viewer"]`；
  - `role_of(user) -> tuple[Role, bool]`：返回身份和 `settings_view`，规则同 CLI 的 `_user_role`；
  - `grants(role, settings_view) -> tuple[bool, list[str]]`：
    - admin → `(True, ["read","write","admin"])`；
    - writer → `(False, ["read","write"])`；
    - viewer → `(False, ["read"])`；
    - viewer + settings_view → `(False, ["read","settings_read"])`；
    - 非 viewer 带 `settings_view` 时抛 `ValueError`。
- `services/user_admin.py`：
  - 函数：
    - `list_users() -> list[dict]`；
    - `create_user(*, email, name, role, settings_view, caller) -> tuple[dict, str]`；
    - `update_user(user_id, *, role=None, settings_view=None, is_active=None, caller) -> dict`；
    - `reset_password(user_id, *, caller, keep_token_hash=None) -> str`。
  - 出错一律抛 `UserAdminError(status, code, detail)`：

    | status | code |
    |---|---|
    | 404 | `not_found` |
    | 409 | `email_taken`、`self_change`、`last_admin` |
    | 422 | `invalid_email`（strip 后 1–255 字）、`invalid_role` |

  - 密码由 `secrets.token_urlsafe(12)` 生成。
  - 停用：删除该用户全部 `Session`，并把他的全部 `APIKey.is_active` 置 false。
  - 启用：删除残留会话，Key 保持作废。
  - 重置密码：删除会话，但保留 `token_hash == keep_token_hash` 的那一个，而且只在用户就是 caller 时保留。
  - 最后一个管理员：统计除目标外、仍启用的管理员，为 0 时拒绝停用或降级。
  - 审计：每次写都调 `AuditService.log("user.create"|"user.update"|"user.disable"|"user.enable"|"user.reset_password", "user", str(id), entity_name=email, user_id=caller.id, user_email=caller.email, old_values=…, new_values=…)`，只记身份 / 状态的前后值，从不记密码。
  - 行字段：`{id, email, name, role, settings_view, is_active, last_login_at, created_at}`。
- `routers/users.py`：
  - 依赖 `async def users_admin(request)` 返回 `await require_authenticated_user(request, admin=settings.api_auth_enabled)`，它在两种模式下都从 Bearer 令牌认出用户（`web/deps.py`）。
  - 四个普通 `def` 路由：`GET /api/users`、`POST /api/users`（201）、`PATCH /api/users/{id}`、`POST /api/users/{id}/reset-password`。
  - `keep_token_hash` 取 Authorization 头里令牌的 sha256，算法同 `AuthService.validate_session`。
  - `UserAdminError` 转成 `JSONResponse({detail, code})`。
