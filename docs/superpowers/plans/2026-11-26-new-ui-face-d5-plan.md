## 每一页（规则放 model 层，便于自测）

1. **所有事项** `#/lib/items`：问题和变更一张表（含结了的）。列：编号、什么事、状态（后端状态的话）、在等谁、级别 / 风险、
   账户、最近变化（UTC）。筛选：全部 / 问题 / 变更；没结的 / 在等你 / agent 在做 / 结了（各带数）；级别；搜索；排序
   （最新、最早、严重度）。一行 → 在等你的去待决，其余去「经过」。示例：16 件在等的 + 5 件不再等的 + 补 ~10 件结了的。
2. **报告** `#/lib/reports`、`/R31`：按 UTC 天分组；类型筛选、搜索、日期；每行：类型、`R#n`、标题、摘要、中 / 英状态、
   私有标记、**谁做的**（定时任务 / 对话 / agent）。阅读页：中英切换（就绪 / 翻译中 / 失败：太长 / 原文改过 = 过期）、
   覆盖范围（读了哪些账户、哪里被截断）、导出 html / pdf / docx（某语言没就绪时按钮不可用并说原因）、发布（选渠道，
   绑定版本 + 语言，重复点只发一次）、「来自对话」的链接。对话里「存成报告」改成真的生成一份并打开（写的人）。
3. **资源** `#/lib/resources`、`/<名字>`：表——名字 + 原生 id、类型、账户、区域、在不在、健康（未知 / 有事在处理 / 有问题 /
   严重 + 原因；没有未结问题 = 未知，不是健康）、未结问题数、最近看到。筛选：类型、健康、含已经不见了的、搜索；每页 50，
   数字和全景的「数据核对」同一个出处（1,623）。详情：健康和原因、未结问题、方案和执行、连着的资源（全景的关系图）、
   原始数据（可折叠）、标签、「在全景里看」`#/world/<名字>`、「问它」。不画「变化记录」——后端没有，写明。
4. **定时任务** `#/lib/schedules`、`/<id>`：**连续失败放在最上面**、红色、写「连续失败 3 次，从 昨天 07:00 UTC 起」；
   每行：启用开关、cron 的白话、上一次（成功 / 失败 + 错误开头 / 在跑 / 从没跑过）、下一次。立刻跑、开关（写的人）。
   详情：配置、每次运行（状态筛选、展开输出、它产出的报告）。
5. **技能** `#/lib/skills`、`/<名字>`：已发布 / 草稿 / agent 写的 / 导入的 / 已归档；最近用过；搜索。详情：正文、参考文件、
   来源（谁写的、从哪导入）、草稿对已发布的差异、发布——**安全检查拦下时列出拦的是哪一行、为什么**、改进建议、
   回滚 / 恢复。导入：URL / Git → 每个包一行（装好了 / 跳过 / 拒绝 + 原因）。
6. **信号** `#/lib/signals`：时间、类型、来源、标题、级别、处理结果（新问题 / 并入 / 噪音 / 出错）**和为什么**（哪条规则；
   灰区由模型判的写把握）、对应的问题；噪音和并入的可以「提成问题」。筛选：处理结果、类型、来源。
7. **安全** `#/lib/security`：每个账户一张卡：总分，或「没有分：读不到 …」（列出读不到的来源；没有分不是满分）、部分读到、
   各类分数、趋势；未结的发现（可达 / 不可达 / 说不准 三种）、建议（复核结论 + 把握）、攻击路径。

每页：四种数据状态、只读的人没有任何写的控件、中英文、手机上表格变成一行一张卡。指令条：命令清单「去哪儿」七页都能去；
搜索的报告组打开报告。`gallery.html` 补：资料页签、表格行、健康四值、连续失败、发布 / 导出按钮的不可用说明、安全分卡。
