## S1 状态可信 + 可访问性 + 定时任务的真实运行状态（2026-11-09）

计划：`docs/superpowers/plans/2026-11-08-mvp-2.8.0-s1-plan.md`。E2E：[`MVP-2.8.0-E2E-REPORT.md`](MVP-2.8.0-E2E-REPORT.md)。

### 共用件（后面七个阶段都用）

- **四种数据状态**：`lib/queryState.queryView` 和 `components/ui/QueryState`。
  - 状态分为加载中、失败（带重试）、空、成功。
  - 「空」只在请求成功、而且确实返回空集合时出现。
  - 刷新失败、手里还有上次的数据时，照常显示旧数据，并标出「刷新失败，正在显示上次成功获取的数据 · 数据截至 HH:MM UTC」，附「重新获取」。
  - 每个模块各套一层，一个失败不会把别的藏起来。
- **状态文字**：`components/ui/StatusText`。状态永远写成文字（一个小圆点 + 文字），颜色只起辅助作用。
- **开关**：`components/ui/Switch`，基于 Radix。
  - `role="switch"` + `aria-checked`。
  - 名称和说明通过 `aria-labelledby` / `aria-describedby` 关联。
  - 可以用 Space / Enter 切换，焦点环可见。
  - 点击区 44 px。
- **浅色主题**改用样本色值：
  - 页面 `#F6F8FC`、正文 `#17243C`、次要文字 `#596B86`、主色 `#2863EB`；
  - 三个状态色：绿 `#167351`、琥珀 `#915B0A`、红 `#B42318`；
  - 暗色主题不变（主人 2.7.0 S2 的决定）。

### 改了什么

| 审阅条目 | 改动 |
|---|---|
| R01 安全页 | 改前：summary 以外的模块在加载中和失败时都是 `data ?? []`，请求失败也显示「没有安全发现」。改后：评分卡片、趋势、雷达、发现、建议、暴露路径六个模块，各自表达四种状态。页头有「刷新」。可达性写成文字：可达 / 无法确定 / 不可达 |
| R03 窄屏标题 | 问题、变更、计划页的标题在长标识符处换行（`overflow-wrap: anywhere`）。窄屏下标题单独占一行 |
| R04 聊天输入区 | 2.7.1 已经改好，这次只复核：390 px 下文本框宽 336 px，320 px 下 266 px |
| R05 开关 | 替换了 16 个手写开关：Settings 的 13 个 `SettingToggle`、消息渠道的开关，以及定时任务表单里的「启用」和「深度调查」。表单里那两个原来是 `div onClick`，键盘到不了。扫描范围的卡片是按钮，补上了 `aria-pressed` |
| R06 全局搜索 | 改用 Radix Dialog：焦点留在弹层内，Esc 关闭，关闭后焦点回到打开它的入口。输入框是 combobox，结果是 listbox，结果数量用读屏播报。搜索失败时显示「搜索失败」和重试，不再显示「没有找到」 |
| R12 工具步骤 | 每一步写明运行中 / 成功 / 失败 / 结果未知。没有 outcome 的历史步骤以前显示成功色，现在写「结果未知」 |
| R16 定时任务 | 后端：`GET /api/schedules` 每行加 `last_execution`，即这个任务最新一条 `schedule_executions`，一次分组查询取出；错误摘要不超过 200 字；从没执行过时为 null；接口改成普通 `def`。前端：配置（已启用 / 已停用）和最近执行分成两列，最近执行为运行中 / 重试中 / 成功 / 失败 / 尚未运行，不认识的状态原样显示，不再从开关推断出「Running」。另有运行时间、下次运行时间和「下一步」链接；cron 的常见写法翻成文字。任务详情页点「立即运行」后显示「已提交，等待执行记录」，最新一条在运行时每 3 秒刷新一次 |
| 时间（R19 的一部分） | `formatShortDate` / `formatFullDate` 末尾加「UTC」。报告列表按 UTC 日分组（以前用浏览器本地日：UTC 16:30 在上海会落到第二天）。另有 9 处用浏览器本地时区显示的时间改成 UTC |
| 窄屏（全局约束） | E2E 实测时发现，S1 改到的页面在 320 / 390 px 下有几处整页横向溢出：计划里的长命令、Schedules 和 Reports 的页头、Settings 的 Galaxy 模型那一行、连接器的运行表。已全部修好 |
