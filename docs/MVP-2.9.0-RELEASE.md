## N0 入口和骨架（2026-11-17）

### 做了什么

| 条目 | 改动 |
|---|---|
| 入口 | 旧界面侧栏 logo 下方固定一项「新界面 NewUI」（不进可拖动的分组），头像菜单和手机菜单里各一项；路由 `/app/new/*` 和登录页一样在旧外壳之外，整套懒加载（自己的 JS 24 kB、CSS 9 kB，gzip 后） |
| 外壳 | 三个视角标签（待决 / 现场 / 全景，`1` `2` `3`；每个视角记得你上次停在哪）、账户范围（和旧界面共用同一个选择）、昼夜（跟随现有的明暗设置，`T`）、语言、帮助（`?`）、「回到旧版」、只读标记、账户菜单（语言、单键快捷键开关、我的 API 密钥、退出登录；手机上还有昼夜、账户范围、回到旧版） |
| 待决队列 | `GET /api/ui/attention?sort=severity`（先严重度，再等得久的），每批 50 件，轮询 30 秒；四个筛选的数字取服务端的 `counts`，取不到时显示「—」而不是 0；地址里写着当前这件事和筛选（`/app/new/decide/I12?f=approval`），刷新、链接、后退都落在同一页 |
| 选中的事离开了队列 | 不悄悄换成另一件：这一页写明「I#12 现在不在等你」，给「看下一件」和旧页面的链接 |
| 通用简报 | 每件事都有一页：它在等什么、哪个资源、去旧页面处理的按钮。之后各阶段给每种情形换上专页；这一页留给新界面不认识的情形，不留白 |
| 只读账户 | 队列按设计是空的：写「只读账户，没有事会派给你」，不写「全部处理完了」 |
| 键盘 | 一处判定（`newui/lib/keys.ts`）：输入法组字中、按着 Ctrl / Cmd / Alt、焦点在输入框里、有对话框或菜单打开时，单键快捷键都不生效；空格和回车留给有焦点的按钮；账户菜单里可以关掉单键快捷键 |
| 样式 | 原型的样式整体搬进 `newui/newui.css`，每条选择器以 `.nf` 开头、动画名以 `nf-` 开头，有测试挡住例外（这份样式随分包加载后不会卸载，不收住会改坏旧页面） |
| 文字 | 新界面自己的 `newui/locales/{zh,en}.json`，随新界面的分包加载，不进首屏包 |

### 和计划不一样的地方

- 计划里说后端给出的组合是 17 种。准确的数是：**17 种情形，16 种可区分的组合**——「检查全过」和「没有结论」在接口上是同一种（`verification_required` / `resolve`），要取回执行结果才分得开。共用清单 `tests/fixtures/attention_brief_kinds.json` 列的是这 16 种，对应 11 种简报。
- 计划里 N0 顺带的「关系图形状的只读统计」挪到 N5 开工时做（那时正好要用）。
