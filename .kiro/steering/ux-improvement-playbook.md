# UX 优化 Playbook

本文档提供 AgenticOps 前后端用户体验优化的方向和具体建议，作为迭代开发的参考。

## 一、Dashboard 优化方向

### 当前状态
- KPI 卡片 + Pipeline 状态栏 + 趋势图 + 三列内容网格
- 数据来自多个独立 hooks（useStats、useAnomalies、useDashboardTrends 等）

### 优化建议
1. **实时数据刷新**：Dashboard 数据目前不自动刷新，可添加 `refetchInterval` 或 WebSocket 推送
2. **趋势图可视化**：当前使用简单的柱状条，可引入轻量图表库（如 recharts）增强可视化
3. **KPI 卡片交互**：部分卡片已支持点击跳转，可扩展到所有卡片
4. **响应式布局**：移动端适配（当前 `grid-cols-2 lg:grid-cols-4`），可优化小屏体验
5. **骨架屏**：替换 Spinner 为骨架屏（Skeleton），减少布局跳动

## 二、Chat 体验优化

### 当前状态
- 三区布局（Session 侧边栏 + 聊天区 + 上下文面板）
- SSE 流式输出 + 文件上传 + 保存为报告

### 优化建议
1. **消息渲染优化**：Markdown 渲染性能优化，长消息虚拟滚动
2. **快捷命令**：输入框支持 `/` 命令提示（如 `/scan`、`/detect`、`/report`）
3. **上下文关联**：消息中的 Issue ID、Resource ID 可点击跳转
4. **会话搜索**：Session 列表支持搜索和排序
5. **消息操作**：支持复制、引用、重新生成等操作
6. **打字指示器**：Agent 思考时显示更丰富的状态（当前工具调用、进度等）

## 三、Issues & Plans 优化

### 当前状态
- Issues 列表 + Resources 列表切换
- 阶段过滤 + 搜索

### 优化建议
1. **批量操作**：支持多选 Issue 批量更新状态
2. **高级筛选**：按严重程度、资源类型、账户、时间范围筛选
3. **排序**：Issue 列表支持按时间、严重程度排序
4. **Issue 卡片视图**：除列表外提供卡片/看板视图
5. **快速操作**：列表行内直接触发 RCA / Fix Plan

## 四、Issue Detail 优化

### 当前状态
- Pipeline Stepper + 操作栏 + Tab（Issue/FixPlan/Timeline）

### 优化建议
1. **实时状态更新**：Pipeline 执行中自动轮询状态
2. **RCA 可视化**：根因分析结果增加关系图/时间线可视化
3. **Fix Plan 对比**：多个 Fix Plan 时支持对比查看
4. **执行日志流式展示**：执行过程中实时展示步骤日志
5. **关联资源图**：展示受影响资源的拓扑关系

## 五、Settings 优化

### 当前状态
- 多 Tab 设置页（Scan Focus、Pipeline、Accounts、MCP、Notifications、KB、Skills、Audit）

### 优化建议
1. **设置搜索**：全局设置搜索功能
2. **配置导入/导出**：一键导出/导入完整配置
3. **变更历史**：设置变更的审计日志
4. **配置验证**：保存前验证配置有效性（如 cron 表达式、AWS 凭证）
5. **引导式配置**：首次使用的引导向导

## 六、全局 UX 优化

### 导航与布局
1. **面包屑导航**：深层页面添加面包屑
2. **快捷键**：扩展 Cmd+K 命令面板功能
3. **通知中心**：右上角通知铃铛，展示最新告警和操作结果
4. **全局搜索增强**：CommandPalette 支持搜索 Issue、Resource、Report

### 性能优化
1. **路由预加载**：hover 导航项时预加载页面
2. **数据缓存策略**：优化 React Query 的 staleTime 和 cacheTime
3. **图片/图标优化**：SVG 图标组件化，减少重复渲染
4. **Bundle 分析**：检查并优化打包体积

### 可访问性
1. **键盘导航**：确保所有交互元素可通过键盘访问
2. **ARIA 标签**：为动态内容添加适当的 ARIA 属性
3. **颜色对比度**：验证 dark/light 模式下的对比度
4. **焦点管理**：模态框和对话框的焦点陷阱

### 错误处理
1. **全局错误边界**：React Error Boundary 捕获渲染错误
2. **网络错误重试**：统一的网络错误重试机制
3. **离线提示**：网络断开时的友好提示
4. **操作撤销**：危险操作支持撤销（如删除）

## 七、后端 API 优化

### 性能
1. **分页优化**：大数据量接口统一分页
2. **查询优化**：N+1 查询检测和优化
3. **缓存层**：热点数据添加缓存（如 Stats、ResourceTypeCounts）
4. **批量接口**：支持批量操作的 API（如批量更新 Issue 状态）

### 实时性
1. **WebSocket**：替代部分轮询场景（如 Pipeline 状态更新）
2. **SSE 扩展**：Dashboard 数据变更推送
3. **事件总线**：后端事件驱动架构，前端订阅感兴趣的事件

### 开发体验
1. **API 文档**：FastAPI 自动生成的 OpenAPI 文档优化
2. **错误码标准化**：统一错误码和错误消息格式
3. **请求日志**：结构化请求日志（含 trace_id）
