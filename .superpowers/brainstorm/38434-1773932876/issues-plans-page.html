A. Unified Pipeline List

Single list of Issues, each row shows the full pipeline progress (open → investigating → rca → fix → resolved). Filter by status phase. Click a row → opens detail in Chat's context panel or as a sub-page. Issue and Fix Plan are one journey, not two lists.

B. Kanban Board

Pipeline stages as columns: Open → RCA → Fix Planned → Executing → Resolved. Cards show severity badge, drag to change status (optional). Visual pipeline overview at a glance. Like Jira/Linear board view.

Key Difference

A. Pipeline List

  • Compact, scannable
  • Works great with Chat context panel
  • Filter by status phase
  • Familiar ops pattern

B. Kanban Board

  • Visual pipeline stages at a glance
  • See bottlenecks instantly
  • Needs more horizontal space
  • Harder to combine with context panel
