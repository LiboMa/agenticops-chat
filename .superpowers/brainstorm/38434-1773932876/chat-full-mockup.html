Interaction Details

Session Flyout

  • Click Chat icon → flyout opens (200px)
  • Click session → loads in chat area
  • Click Chat icon again → flyout closes
  • + button creates new session
  • Search filters sessions

Context Panel

  • Click Issue card in chat → panel opens
  • Drag handle to resize (30-70% range)
  • Tabs: Issue / Fix Plan / Timeline
  • X button closes panel, chat goes full width
  • Panel remembers last width
