Design Decisions

Decision Choice
Interaction model Hybrid — Chat core + Dashboard overview
Shell layout 52px icon sidebar (hover labels)
Chat context panel Resizable split + tabs (Issue / Fix Plan / Timeline)
Session management Chat icon flyout panel (200px, toggle open/close)
Send message Cmd/Ctrl+Enter to send, Enter for newline
Issues + Fix Plans Unified pipeline list with inline status stepper
Dashboard Full modules: Issues summary, Resources, Active Fix Plans, Recent Activity, Scheduled Jobs, Trends
i18n Auto-detect browser language + manual CN/EN switch, persisted to localStorage
Tech stack React + TypeScript + Tailwind + Radix UI (unchanged)

Page Architecture

// Routes
/app → Dashboard (KPIs, Resources, Issues summary, Trends, Activity)
/app/chat → Chat (session flyout + messages + context panel)
/app/chat/:sessionId → Chat (specific session)
/app/issues → Issues & Plans (unified pipeline list)
/app/issues/:id → Issue Detail (or open in Chat context panel)
/app/schedules → Schedules (list + detail)
/app/schedules/:id → Schedule Detail
/app/reports → Reports (list + detail)
/app/reports/:id → Report Detail
/app/settings → Settings (tabs: General, Accounts, Notifications, Audit, KB, Skills, MCP)
